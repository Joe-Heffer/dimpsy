## Works without a network

The lamp works fully with no Wi-Fi, no phone and no smart home system, and it does so by default. Everything needed in daily use is reached from the physical controls, and the schedule runs from the real-time clock.

Wi-Fi, the web page and any smart home link are optional extras for setting up and tuning. Linking Dimpsy to a smart home system is welcome, but it must never be required, and it is off unless the owner turns it on. Less screen time at bedtime is a goal, so nothing the lamp does at night should need a screen.

The checks for this on the prototype are in [issue #44](https://github.com/Joe-Heffer/dimpsy/issues/44).
